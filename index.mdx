```python Your first encrypted query icon="python"
# pip install cyborgdb-core   (Python 3.10+)
import cyborgdb_core as cyborgdb
import secrets

client = cyborgdb.Client(storage_config=cyborgdb.StorageConfig.disk("/tmp/cyborgdb"))
index_key = secrets.token_bytes(32)  # store this securely: a lost key means lost data
index = client.create_index(index_name="my_index", index_key=index_key)

index.upsert([{"id": "a", "vector": [0.1, 0.2, 0.3, 0.4], "contents": "Hello!"}], index_key=index_key)
results = index.query(query_vectors=[0.1, 0.2, 0.3, 0.4], top_k=1, index_key=index_key)
```

<p className="cdb-home-note">Runs locally, with no server and no API key (the free tier allows up to 1M items per index). The <a href="/versions/latest/intro/quickstart">Quickstart</a> walks through it end to end.</p>
