The **CyborgDB** Go SDK is a client for the CyborgDB service. It creates encrypted indexes, upserts and retrieves vectors, runs vector, hybrid (BM25 + vector), and metadata-only queries, and manages per-index users. Every call that reaches the service takes a `context.Context`, and failures return [typed errors](./errors).

The source code is on [GitHub](https://github.com/cyborginc/cyborgdb-go).

## Installation

```bash
go get github.com/cyborginc/cyborgdb-go
```

The package name is `cyborgdb`:

```go
import "github.com/cyborginc/cyborgdb-go"
```

## Prerequisites

The SDK needs a running CyborgDB service:

```bash
# Install and start the service
pip install cyborgdb-service
cyborgdb-service

# Or run the Docker image
docker run -p 8000:8000 cyborginc/cyborgdb-service
```

See the quickstart guides for [Docker](../guides/intro/quickstart-docker) and [Python](../guides/intro/quickstart-python).
