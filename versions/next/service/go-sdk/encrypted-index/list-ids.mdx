Returns every item ID in the index.

```go
func (e *EncryptedIndex) ListIDs(ctx context.Context) (*ListIDsResponse, error)
```

### Returns

`*ListIDsResponse` with `Ids []string` (all IDs, in no particular order) and `Count int32`. The full list is returned in one response; there is no pagination.

### Errors

| Error | Returned when |
|-------|---------------|
| `*AuthenticationError` | The `apiKey` is invalid (HTTP `401`). |
| `*ServiceError` / `*TransportError` | The service returns `5xx` or can't be reached. |

See [Errors](../errors).

### Example Usage

```go
res, err := index.ListIDs(ctx)
if err != nil {
    log.Fatal(err)
}
fmt.Println(res.Count, slices.Contains(res.Ids, "doc1"))
// Output: 3 true

// Fetch items in batches of 100
for i := 0; i < len(res.Ids); i += 100 {
    batch, err := index.Get(ctx, res.Ids[i:min(i+100, len(res.Ids))], nil)
    if err != nil {
        log.Fatal(err)
    }
    _ = batch
}
```
