Permanently removes items from the index by ID, along with their contents and metadata.

```go
func (e *EncryptedIndex) Delete(ctx context.Context, ids []string) error
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `ctx` | `context.Context` | Context for cancellation and deadlines. |
| `ids` | `[]string` | IDs of the items to delete. An empty slice is a no-op. |

### Returns

`error` only; `nil` on success.

### Errors

| Error | Returned when |
|-------|---------------|
| `*AuthenticationError` | The `apiKey` is invalid, or a read-only user key is used (HTTP `401`/`403`). |
| `*ServiceError` / `*TransportError` | The service returns `5xx` or can't be reached. |

See [Errors](../errors).

### Example Usage

```go
if err := index.Delete(ctx, []string{"doc1", "doc2"}); err != nil {
    log.Fatal(err)
}

ids, err := index.ListIDs(ctx)
if err != nil {
    log.Fatal(err)
}
fmt.Println(ids.Ids)
// Output: [doc3]
```
