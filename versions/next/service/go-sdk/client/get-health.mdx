Returns the health status of the CyborgDB service, to check that it is reachable and running.

```go
func (c *Client) GetHealth(ctx context.Context) (map[string]string, error)
```

### Returns

A `map[string]string` with these keys:

| Key | Description |
|-----|-------------|
| `status` | Service health, `"healthy"` when the service is up. |
| `api_version` | REST API version, e.g. `"v1"`. |
| `version` | CyborgDB service version. |

### Errors

| Error | Returned when |
|-------|---------------|
| `*TransportError` | The service can't be reached. |
| `*ServiceError` | The service returns `5xx`. |

See [Errors](../errors).

### Example Usage

```go
package main

import (
    "context"
    "fmt"
    "log"

    "github.com/cyborginc/cyborgdb-go"
)

func main() {
    client, err := cyborgdb.NewClient("http://localhost:8000", "your-api-key")
    if err != nil {
        log.Fatal(err)
    }

    health, err := client.GetHealth(context.Background())
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(health)
    // Output: map[api_version:v1 status:healthy version:0.18.0]
}
```
