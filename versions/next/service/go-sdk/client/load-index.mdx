Loads an existing encrypted index and returns an `*EncryptedIndex` bound to it.

```go
func (c *Client) LoadIndex(ctx context.Context, indexName string, indexKey []byte) (*EncryptedIndex, error)
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `ctx` | `context.Context` | Context for cancellation and deadlines. |
| `indexName` | `string` | Name of an existing index. |
| `indexKey` | `[]byte` | The 32-byte key the index was created with. Required for SDK-supplied-key indexes; pass `nil` for KMS-backed indexes (created with `KmsName`). |

<Warning>For SDK-supplied-key indexes, `indexKey` must be the exact key passed to `CreateIndex`. A KMS-backed index fails to load if its `KmsName` slot is missing from the service YAML or its provider is unreachable.</Warning>

### Returns

The `*EncryptedIndex` bound to the loaded index. `LoadIndex` calls the service's describe endpoint before returning, so a missing index or a wrong key fails here, not on the first query.

### Errors

| Error | Returned when |
|-------|---------------|
| `*ValidationError` wrapping `ErrInvalidKeyLength` | `indexKey` is non-empty but not 32 bytes. Returned before any request is sent. |
| `*NotFoundError` | No index named `indexName` exists, or `indexKey` doesn't match it (HTTP `404`). |
| `*AuthenticationError` | The client's `apiKey` is missing or invalid (HTTP `401`). |
| `*ServiceError` | The service returns `5xx`, for example when a KMS-backed index's provider is unavailable. |
| `*TransportError` | The service can't be reached. |

See [Errors](../errors).

### Example Usage

#### SDK-supplied-key index

```go
package main

import (
    "context"
    "encoding/hex"
    "fmt"
    "log"

    "github.com/cyborginc/cyborgdb-go"
)

func main() {
    client, err := cyborgdb.NewClient("http://localhost:8000", "your-api-key")
    if err != nil {
        log.Fatal(err)
    }

    // The same 32 bytes that were passed to CreateIndex, e.g. stored as hex
    key, err := hex.DecodeString("your-64-character-hex-key")
    if err != nil {
        log.Fatal(err)
    }

    index, err := client.LoadIndex(context.Background(), "my-index", key)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(index.GetIndexName())
    // Output: my-index
}
```

#### KMS-backed index

```go
// No key needed: the service unwraps it with the index's KMS provider.
index, err := client.LoadIndex(ctx, "kms-index", nil)
if err != nil {
    log.Fatal(err)
}
_ = index
```
