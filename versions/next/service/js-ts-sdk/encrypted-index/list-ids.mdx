Returns every item ID in the index.

```typescript
async listIds(): Promise<{ ids: string[]; count: number }>
```

### Returns

`Promise<{ ids, count }>`: all IDs in the index, in no particular order, and how many there are. The full list is returned in one response; there is no pagination.

### Exceptions

| Exception | Thrown when |
|-----------|-------------|
| `CyborgDBAuthenticationError` | The `indexKey` or `apiKey` is invalid (HTTP `401`). |
| `CyborgDBServiceError` | The service returns `5xx`. |

See [Errors](../errors) for the full hierarchy.

### Example Usage

```typescript
const { ids, count } = await index.listIds();
console.log(count);
// Output: 3

console.log(ids.includes('doc1'));
// Output: true

// Fetch items in batches of 100
for (let i = 0; i < ids.length; i += 100) {
    const items = await index.get({ ids: ids.slice(i, i + 100) });
}
```
