Loads an existing encrypted index and returns an `EncryptedIndex` bound to it.

```python
client.load_index(
    index_name,
    index_key = None,
)
```

### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `index_name` | `str` | - | Name of an existing index. |
| `index_key` | `bytes` | `None` | _(Optional)_ The 32-byte key the index was created with. Required for SDK-supplied-key indexes; omit it for KMS-backed indexes (created with `kms_name`). |

<Warning>For SDK-supplied-key indexes, `index_key` must be the exact key passed to `create_index()`. A KMS-backed index fails to load if its `kms_name` slot is missing from the service YAML or its provider is unreachable.</Warning>

### Returns

An `EncryptedIndex` bound to the loaded index. `load_index()` calls the service's describe endpoint before returning, so a missing index or a wrong key fails here, not on the first query.

### Exceptions

| Exception | Raised when |
|-----------|-------------|
| `ValueError` | `index_key` is passed but is not 32 bytes. Raised before any request is sent. |
| `cyborgdb.NotFoundError` | No index named `index_name` exists (HTTP `404`). |
| `cyborgdb.AuthenticationError` | `index_key` doesn't match the index, or the client's `api_key` is missing or invalid (HTTP `401`). |
| `cyborgdb.ServiceError` | The service returns `5xx`, for example when a KMS-backed index's provider is unavailable. |
| `cyborgdb.TransportError` | The service can't be reached. |

See [Errors](../errors) for the full hierarchy.

### Example Usage

#### SDK-supplied-key index

```python
from cyborgdb import Client

client = Client(base_url='http://localhost:8000', api_key='your-api-key')

# The same 32 bytes that were passed to create_index(), e.g. stored as hex
index_key = bytes.fromhex('your-64-character-hex-key')

index = client.load_index('my_index', index_key)
print(index.index_name)
# Output: my_index
```

#### KMS-backed index

```python
# No key needed: the service unwraps it with the index's KMS provider.
index = client.load_index('kms_index')
```
