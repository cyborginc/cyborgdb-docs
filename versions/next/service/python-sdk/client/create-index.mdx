Creates a new encrypted DiskIVF index on the service and returns an `EncryptedIndex` bound to it.

```python
client.create_index(
    index_name,
    index_key = None,
    kms_name = None,
    dimension = None,
    embedding_model = None,
    metric = None,
    storage_precision = None,
    metadata_schema = None,
    text_fields = None,
    bm25_k1 = None,
    bm25_b = None,
)
```

<Note>Since v0.17 there is one index type, DiskIVF, configured with flat keyword arguments. The v0.16 `IndexIVFFlat`, `IndexIVFPQ`, and `IndexIVFSQ` types and the `index_config` argument no longer exist.</Note>

### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `index_name` | `str` | - | Unique name for the index. |
| `index_key` | `bytes` | `None` | _(Optional)_ 32-byte encryption key (SDK-supplied KEK). Pass either `index_key` or `kms_name`, never both. |
| `kms_name` | `str` | `None` | _(Optional)_ Name of a `kms.registry` entry in the service YAML. The service generates the KEK and wraps it with that provider; the SDK never sees the plaintext key. |
| `dimension` | `int` | `None` | _(Optional)_ Vector dimensionality. When omitted, the service detects it from the first upsert. |
| `embedding_model` | `str` | `None` | _(Optional)_ sentence-transformers model name for automatic embedding generation. When set, `dimension` is taken from the model. |
| `metric` | `str` | `None` (service default: `"euclidean"`) | _(Optional)_ `"euclidean"`, `"squared_euclidean"`, or `"cosine"`. |
| `storage_precision` | `str` | `None` (service default: `"float32"`) | _(Optional)_ Storage format for rerank vectors. See [Storage precision](#storage-precision). |
| `metadata_schema` | `Dict[str, Dict[str, bool]]` | `None` | _(Optional)_ Per-field metadata indexing policy. Fixed at creation and cannot be changed later. See [Metadata schema](#metadata-schema). |
| `text_fields` | `List[str]` | `None` | _(Optional)_ Metadata fields to index for BM25 full-text search. Shorthand for `{"full_text": True}` in `metadata_schema`. Enables `text=` on [`query()`](../encrypted-index/query) and [`query_metadata()`](../encrypted-index/query-metadata). |
| `bm25_k1` | `float` | `None` (service default: `1.2`) | _(Optional)_ BM25 term-frequency saturation, `>= 0`. Requires at least one full-text field. |
| `bm25_b` | `float` | `None` (service default: `0.75`) | _(Optional)_ BM25 length-normalization strength, in `[0, 1]`. Requires at least one full-text field. |

### Key management

Pass exactly one of `index_key` or `kms_name`. The service rejects both together with `ValidationError` (HTTP `400`), whatever the KMS provider.

- **SDK-supplied KEK:** pass `index_key`. Supply the same key again on every [`load_index()`](./load-index).
- **KMS-backed:** pass `kms_name`. The service generates the key, wraps it with the named provider, and stores the wrapped key. Later calls omit `index_key`.

### Storage precision

`storage_precision` sets how the full-precision rerank vectors are stored. Every value works with every metric.

| Value | Bits per dimension | Notes |
|-------|--------------------|-------|
| `"float32"` | 32 | Default. |
| `"float16"` | 16 | Half the storage of `float32`, with a small precision cost. |
| `"tq12"` | 12 | TurboQuant. |
| `"tq8"` | 8 | TurboQuant. |
| `"tq6"` | 6 | TurboQuant. |
| `"tq4"` | 4 | TurboQuant. About 8x smaller than `float32`, at about 94% recall@100. |

Lower TurboQuant tiers use less storage in exchange for a small recall and latency cost.

### Metadata schema

`metadata_schema` sets how each metadata field is indexed. Metadata itself stays schemaless: this controls indexing, not what may be stored. Fields left out get the default policy (indexed and filterable). Nested fields use dot-paths such as `"loc.city"`.

```python
metadata_schema = {
    "title":         {"filterable": True, "pattern": True},  # regex-searchable
    "internal_blob": {"filterable": False},                   # stored, not indexed
    "body":          {"full_text": True},                     # BM25 full-text search
}
```

Each field takes three settings:

| Setting | Default | Effect |
|---------|---------|--------|
| `filterable` | `True` | Builds inverted-index postings, so filters on the field resolve from the index. `False` still stores the field, but [`query()`](../encrypted-index/query) filters on it fall back to a slower post-filter, and [`query_metadata()`](../encrypted-index/query-metadata) rejects them. |
| `pattern` | `False` | Also builds a regex dictionary, so `$regex` and `$contains` resolve from the index. Requires `filterable=True`. |
| `full_text` | `False` | Sends the field's text through the BM25 analyzer instead of exact-match indexing. Implies `filterable=False`, and can't be combined with `pattern=True`. |

On `query()` the schema is a performance hint: filters the index can't answer fall back to a post-filter on the decrypted metadata. On `query_metadata()` it is enforced, and unsupported filters return `ValidationError`.

The stored policy is returned by the [`metadata_schema`](../getters#metadata_schema) getter.

### Returns

An `EncryptedIndex` bound to the new index. For KMS-backed indexes it holds no plaintext key.

### Exceptions

| Exception | Raised when |
|-----------|-------------|
| `ValueError` | Neither `index_key` nor `kms_name` is passed; `index_key` is not 32 bytes; or `storage_precision` is not one of the six values above. Raised before any request is sent. |
| `cyborgdb.ValidationError` | The service rejects the request (HTTP `400`): the index name already exists, both `index_key` and `kms_name` were passed, the `kms_name` slot is unknown, or `metadata_schema` combines settings that aren't allowed. |
| `cyborgdb.ServiceError` | The service returns `5xx`, including KMS wrap failures (`502`). |
| `cyborgdb.TransportError` | The service can't be reached. |

See [Errors](../errors) for the full hierarchy.

### Example Usage

#### SDK-supplied key

```python
from cyborgdb import Client

client = Client(base_url='http://localhost:8000', api_key='your-api-key')

index_key = client.generate_key()

# The dimension is detected from the first upsert
index = client.create_index('documents', index_key=index_key)
```

<Note>Store `index_key` securely: it is needed to load the index again. See [Generate Key](./generate-key).</Note>

#### Explicit dimension and metric

```python
index = client.create_index(
    'documents_384',
    index_key=index_key,
    dimension=384,
    metric='cosine',
)
```

#### KMS-backed index

```python
# The service generates the key and wraps it with the 'prod-aws' registry slot.
index = client.create_index(
    'kms_documents',
    kms_name='prod-aws',
    dimension=384,
)
# Later calls, including load_index(), omit index_key.
```

#### Automatic embeddings

```python
# The dimension is taken from the embedding model
index = client.create_index(
    'semantic_docs',
    index_key=index_key,
    embedding_model='all-MiniLM-L6-v2',
)
```

See [Auto-Generate Embeddings](../../guides/data-operations/add-items#automatic-embedding-generation).

#### Reduced storage with TurboQuant

```python
index = client.create_index(
    'compact_docs',
    index_key=index_key,
    dimension=768,
    storage_precision='tq8',
)
```

#### Per-field metadata policy

```python
index = client.create_index(
    'docs_index',
    index_key=index_key,
    dimension=4,
    metadata_schema={
        'title':         {'filterable': True, 'pattern': True},
        'internal_blob': {'filterable': False},
    },
)
index.upsert([
    {'id': 'doc1', 'vector': [0.1, 0.2, 0.3, 0.4], 'metadata': {'title': 'intro to encryption'}},
    {'id': 'doc2', 'vector': [0.5, 0.6, 0.7, 0.8], 'metadata': {'title': 'advanced setup'}},
])

# $regex resolves from the index because 'title' has pattern=True
print(index.query_metadata(filters={'title': {'$regex': '^intro'}}))
# Output: [{'id': 'doc1'}]
```

#### Full-text search fields

```python
index = client.create_index(
    'articles',
    index_key=index_key,
    dimension=4,
    text_fields=['body'],
)
print(index.bm25)
# Output: {'k1': 1.2, 'b': 0.75, 'analyzer_version': 'en/1;sw=2de831ef7be676b6;snowball-english-utf8-3.0.1'}
```
