Returns the names of all indexes on the CyborgDB service.

```python
client.list_indexes()
```

### Returns

`List[str]`: index names. Empty when the service has no indexes.

### Exceptions

| Exception | Raised when |
|-----------|-------------|
| `cyborgdb.AuthenticationError` | The client's `api_key` is missing or invalid (HTTP `401`). |
| `cyborgdb.ServiceError` | The service returns `5xx`. |
| `cyborgdb.TransportError` | The service can't be reached. |

See [Errors](../errors) for the full hierarchy.

### Example Usage

```python
from cyborgdb import Client

client = Client(base_url='http://localhost:8000', api_key='your-api-key')

indexes = client.list_indexes()
print(indexes)
# Output: ['documents', 'embeddings', 'semantic-search']
```
