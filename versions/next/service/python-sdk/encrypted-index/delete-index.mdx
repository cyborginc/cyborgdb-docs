<Warning>Deleting an index is irreversible.</Warning>

Deletes the index and all of its data from the CyborgDB service.

```python
index.delete_index()
```

### Returns

`None`

### Exceptions

<AccordionGroup>
    <Accordion title="cyborgdb.NotFoundError">
        The index doesn't exist, for example because it was already deleted (HTTP `404`).
    </Accordion>
    <Accordion title="cyborgdb.AuthenticationError">
        The `index_key` or `api_key` is invalid (HTTP `401`), or the client is using a per-user key: deleting an index requires the root key (HTTP `403`).
    </Accordion>
    <Accordion title="cyborgdb.ServiceError / cyborgdb.TransportError">
        The service returns `5xx` or can't be reached.
    </Accordion>
</AccordionGroup>

See [Errors](../errors) for the full hierarchy.

### Example Usage

```python
index.delete_index()
print(index.index_name in client.list_indexes())
# Output: False
```
