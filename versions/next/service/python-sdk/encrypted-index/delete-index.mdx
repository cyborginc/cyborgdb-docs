<Warning>Deleting an index is irreversible.</Warning>

Deletes the index and all of its data from the CyborgDB service.

```python
index.delete_index()
```

### Returns

`None`

### Exceptions

| Exception | Raised when |
|-----------|-------------|
| `cyborgdb.NotFoundError` | The index doesn't exist, for example because it was already deleted (HTTP `404`). |
| `cyborgdb.AuthenticationError` | The `index_key` or `api_key` is invalid (HTTP `401`). |
| `cyborgdb.ServiceError` / `cyborgdb.TransportError` | The service returns `5xx` or can't be reached. |

See [Errors](../errors) for the full hierarchy.

### Example Usage

```python
index.delete_index()
print(index.index_name in client.list_indexes())
# Output: False
```
