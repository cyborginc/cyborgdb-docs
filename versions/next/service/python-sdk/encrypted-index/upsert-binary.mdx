`upsert_binary()` sends vectors as base64-encoded little-endian `float32` instead of JSON arrays, which is faster for large batches. Unlike the two-argument form of [`upsert()`](./upsert), it also takes parallel `metadata`.

```python
index.upsert_binary(
    ids,
    vectors,
    metadata=None,
    contents=None,
)
```

### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `ids` | `List[str]` | - | Unique identifier for each vector. Length must equal `vectors.shape[0]`. |
| `vectors` | `np.ndarray` (shape `(n, dim)`) | - | Vector data. Cast to little-endian `float32` if needed. |
| `metadata` | `List[Optional[Dict]]` | `None` | _(Optional)_ Metadata per vector, same length as `ids`. Use `None` for entries without metadata. |
| `contents` | `List[Optional[str \| bytes]]` | `None` | _(Optional)_ Contents per vector. **Not usable yet:** see the warning below. |

<Warning>Passing any `str` or `bytes` value in `contents` currently raises `pydantic.ValidationError`. To store contents, use the item-dict form of [`upsert()`](./upsert).</Warning>

### Returns

`None`

### Exceptions

| Exception | Raised when |
|-----------|-------------|
| `TypeError` | `vectors` is not a NumPy array. |
| `ValueError` | `vectors` is not 2-D, or `ids`, `metadata`, or `contents` differ in length from `vectors`. |
| `cyborgdb.ValidationError` | The service rejects the batch (HTTP `400`), for example a vector with the wrong dimension. |
| `cyborgdb.ServiceError` / `cyborgdb.TransportError` | The service returns `5xx` or can't be reached. |

See [Errors](../errors) for the full hierarchy.

### Example Usage

```python
import numpy as np

ids = ["vec1", "vec2", "vec3"]
vectors = np.random.rand(3, 4).astype(np.float32)
metadata = [
    {"category": "news", "lang": "en"},
    {"category": "research"},
    None,
]

index.upsert_binary(ids, vectors, metadata=metadata)
```

<Tip>For small batches, the item-dict form of [`upsert()`](./upsert) is easier to read. Use `upsert_binary()` when the vectors are already a NumPy array and JSON encoding time matters.</Tip>
