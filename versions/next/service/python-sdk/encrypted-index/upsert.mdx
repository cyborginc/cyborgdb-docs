Adds vectors to the index, or replaces existing vectors with the same ID. `upsert()` takes one of two shapes:

```python
# Shape 1: a list of item dicts
index.upsert(items)

# Shape 2: parallel arrays of IDs and a NumPy array of vectors
index.upsert(ids, vectors)
```

### Parameters

#### Shape 1: list of item dicts

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `items` | `List[Dict]` | - | One dict per vector. |

Each dict can contain:

```python
{
    "id": str,               # Required. Unique identifier.
    "vector": List[float],   # Optional if the index has an embedding model and "contents" is set.
    "contents": str | bytes, # Optional. Encrypted before storage.
    "metadata": Dict,        # Optional. Key-value pairs for filtering.
}
```

`contents` accepts a `str` or `bytes`. Strings are stored as-is; bytes are base64-encoded first. [`get()`](./get) always returns `contents` as a `str`, so bytes come back as their base64 text: decode them with `base64.b64decode()`.

<Tip>Store dates in `metadata` as integer epoch milliseconds so range filters work on them. See [Dates](../types#dates).</Tip>

#### Shape 2: parallel arrays

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `ids` | `List[str]` | - | Unique identifier for each vector. |
| `vectors` | `np.ndarray` (shape `(n, dim)`) | - | Vector data. Sent as binary through [`upsert_binary()`](./upsert-binary). |

Shape 2 can't attach metadata or contents. To send metadata with parallel arrays, call [`upsert_binary()`](./upsert-binary) directly.

### Returns

`None`

### Exceptions

| Exception | Raised when |
|-----------|-------------|
| `TypeError` / `ValueError` | The arguments don't match either shape, or the IDs and vectors differ in length. Raised before any request is sent. |
| `cyborgdb.ValidationError` | The service rejects the items (HTTP `400`), for example a vector with the wrong dimension. |
| `cyborgdb.AuthenticationError` | The `index_key` or `api_key` is invalid (HTTP `401`). |
| `cyborgdb.ServiceError` | The service returns `5xx`. |
| `cyborgdb.TransportError` | The service can't be reached. |

See [Errors](../errors) for the full hierarchy.

### Example Usage

#### Item dicts

```python
items = [
    {"id": "doc1", "vector": [0.1, 0.2, 0.3, 0.4], "contents": "First document"},
    {"id": "doc2", "vector": [0.5, 0.6, 0.7, 0.8], "metadata": {"category": "news"}},
]

index.upsert(items)
```

#### Parallel arrays

```python
import numpy as np

ids = ["vec1", "vec2", "vec3"]
vectors = np.random.rand(3, 4).astype(np.float32)

index.upsert(ids, vectors)
```

#### Parallel arrays with metadata

```python
import numpy as np

ids = ["vec4", "vec5", "vec6"]
vectors = np.random.rand(3, 4).astype(np.float32)
metadata = [{"category": "news"}, {"category": "research"}, None]

index.upsert_binary(ids, vectors, metadata=metadata)
```
