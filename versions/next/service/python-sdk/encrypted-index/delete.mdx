Permanently removes items from the index by ID, along with their contents and metadata.

```python
index.delete(ids)
```

### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `ids` | `List[str]` | - | IDs of the items to delete. An empty list is a no-op. |

### Returns

`None`

### Exceptions

<AccordionGroup>
    <Accordion title="cyborgdb.ValidationError">
        The service rejects the request (HTTP `422`), for example when `ids` isn't a list of strings.
    </Accordion>
    <Accordion title="cyborgdb.AuthenticationError">
        The `index_key` or `api_key` is invalid (HTTP `401`).
    </Accordion>
    <Accordion title="cyborgdb.ServiceError / cyborgdb.TransportError">
        The service returns `5xx` or can't be reached.
    </Accordion>
</AccordionGroup>

See [Errors](../errors) for the full hierarchy.

### Example Usage

```python
index.delete(["doc1", "doc2"])
print(index.list_ids())
# Output: ['doc3']
```
