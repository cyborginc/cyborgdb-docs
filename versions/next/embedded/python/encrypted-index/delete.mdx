<Warning>This action is irreversible. Proceed with caution.</Warning>

Deletes the specified encrypted items stored in the index, including all its associated fields (`vector`, `contents`, `metadata`).

```python
def delete(self,
           ids: List[str],
           *,
           index_key: bytes,
           user_id: bytes = None)
```

### Parameters

| Parameter | Type | Description |
|-------------------|--------------------|-----------------------|
| `ids` | `List[str]` | IDs to delete. |
| `index_key` | `bytes` | _(Required, keyword-only)_ 32-byte index KEK. See [Index key](#index-key). |
| `user_id` | `bytes` | _(Optional, keyword-only)_ 16-byte RBAC user identifier. See [Index key](#index-key). |

### Exceptions

<AccordionGroup>
    <Accordion title="RuntimeError">
        - Throws if the items could not be deleted.
    </Accordion>
</AccordionGroup>

### Example Usage

```python
# Load index
index = client.load_index(
    index_name=index_name, 
    index_key=index_key
)

# Delete "item_1" and "item_2"
index.delete(["item_1", "item_2"], index_key=index_key)
```

### Index key

`index_key` is required on every call. Pass the same 32-byte index KEK you used with [`create_index()`](../client/create-index) / [`load_index()`](../client/load-index). For an [RBAC user](./manage-users), pass the user's KEK as `index_key=` together with their `user_id=`:

```python
index.delete(["item_1", "item_2"], index_key=user_kek, user_id=user_id)
```

<Note>Deleting items requires write permission. An [RBAC user](./manage-users) without a write wrap cannot delete items.</Note>
