Returns the names of all indexes on the CyborgDB service.

```typescript
async listIndexes(): Promise<string[]>
```

### Returns

`Promise<string[]>`: index names. Empty when the service has no indexes.

### Exceptions

<AccordionGroup>
    <Accordion title="CyborgDBAuthenticationError">
        The client's `apiKey` is missing or invalid (HTTP `401`), or is a per-user key: listing indexes requires the root key (HTTP `403`).
    </Accordion>
    <Accordion title="CyborgDBServiceError">
        The service returns `5xx`.
    </Accordion>
    <Accordion title="CyborgDBTransportError">
        The service can't be reached.
    </Accordion>
</AccordionGroup>

See [Errors](../errors) for the full hierarchy.

### Example Usage

```typescript
import { Client } from 'cyborgdb';

const client = new Client({ baseUrl: 'http://localhost:8000', apiKey: 'your-api-key' });

const indexes = await client.listIndexes();
console.log(indexes);
// Output: [ 'documents', 'embeddings', 'semantic-search' ]
```
