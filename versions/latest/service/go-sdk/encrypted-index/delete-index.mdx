<Warning>Deleting an index is irreversible.</Warning>

Deletes the index and all of its data from the CyborgDB service.

```go
func (e *EncryptedIndex) DeleteIndex(ctx context.Context) error
```

### Returns

`error` only; `nil` on success.

### Errors

<AccordionGroup>
    <Accordion title="*NotFoundError">
        The index doesn't exist, for example because it was already deleted (HTTP `404`).
    </Accordion>
    <Accordion title="*AuthenticationError">
        The `apiKey` is invalid (HTTP `401`), or the client is using a per-user key: deleting an index requires the root key (HTTP `403`).
    </Accordion>
    <Accordion title="*ServiceError / *TransportError">
        The service returns `5xx` or can't be reached.
    </Accordion>
</AccordionGroup>

See [Errors](../errors).

### Example Usage

```go
if err := index.DeleteIndex(ctx); err != nil {
    log.Fatal(err)
}

names, err := client.ListIndexes(ctx)
if err != nil {
    log.Fatal(err)
}
fmt.Println(slices.Contains(names, index.GetIndexName()))
// Output: false
```
