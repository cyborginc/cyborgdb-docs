Returns every item ID in the index.

```python
index.list_ids()
```

### Returns

`List[str]`: all IDs in the index.

### Exceptions

<AccordionGroup>
    <Accordion title="cyborgdb.AuthenticationError">
        The `index_key` or `api_key` is invalid (HTTP `401`).
    </Accordion>
    <Accordion title="cyborgdb.ServiceError / cyborgdb.TransportError">
        The service returns `5xx` or can't be reached.
    </Accordion>
</AccordionGroup>

See [Errors](../errors) for the full hierarchy.

### Example Usage

```python
all_ids = index.list_ids()
print(len(all_ids))
# Output: 3

print("doc1" in all_ids)
# Output: True

# Fetch items in batches of 100
for i in range(0, len(all_ids), 100):
    items = index.get(all_ids[i:i + 100])
```
